This is the first post on the new site. It is built with Hugo and the `hugo-noir` theme, with a few layout overrides to support content-driven sections.

## Why this setup?

- **Static**: No backend, no database, no accounts.
- **Fast**: The entire site is pre-built HTML and CSS.
- **Maintainable**: Write Markdown, run `hugo`, publish.
- **Extensible**: The architecture leaves room for future private content.
